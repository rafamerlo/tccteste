## <span style="color:#FF2638">01.</span> VISÃO GERAL

O **TCC 2026** é um projeto desenvolvido como parte do Trabalho de Conclusão de Curso.

Este repositório centraliza o desenvolvimento, a documentação e os recursos relacionados à solução proposta.

O objetivo é transformar conhecimentos adquiridos durante a formação acadêmica em uma aplicação prática, organizada e funcional.

> Desenvolver, inovar e transformar conhecimento em tecnologia.

---

## <span style="color:#FF2638">02.</span> OBJETIVOS

O projeto busca integrar teoria e prática por meio do desenvolvimento de uma solução tecnológica.

**Principais objetivos:**

- Aplicar conhecimentos adquiridos durante a formação acadêmica.
- Desenvolver uma solução para o problema proposto.
- Organizar e documentar as etapas do projeto.
- Utilizar ferramentas e tecnologias adequadas.
- Validar os resultados obtidos durante o desenvolvimento.

## <span style="color:#FF2638">05.</span> INSTALAÇÃO

Para executar o projeto localmente, siga os passos abaixo.

**1. Clone o repositório**

```bash
git clone https://github.com/AndressaPapini/TCC-2026.git
```

**2. Entre no diretório**

```bash
cd TCC-2026
```

**3. Instale as dependências**

Utilize o gerenciador de pacotes correspondente às tecnologias do projeto.

**4. Execute a aplicação**
